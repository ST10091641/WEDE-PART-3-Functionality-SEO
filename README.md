# WEDE-PART-3-Functionality-SEO# For The People — Community Gardening Website

## Project Overview
A comprehensive community gardening website built with React, TypeScript, and Tailwind CSS. The platform connects communities with sustainable gardening resources, educational content, and volunteer opportunities.

## Features
- **Responsive Design**: Mobile-first approach with seamless experience across all devices
- **Form Validation**: Client-side validation with real-time feedback
- **SEO Optimized**: Meta tags, Open Graph, and structured content
- **Interactive UI**: Animations, transitions, and dynamic content
- **Search Functionality**: Filter plants by soil type and search terms
- **Contact & Enquiry Forms**: Fully functional forms with validation and success states

## Tech Stack
- React 18 with TypeScript
- Vite for build tooling
- Tailwind CSS for styling
- React Router for navigation
- React Helmet Async for SEO
- Lucide React for icons

## Pages
1. **Home** — Hero section with features and mission
2. **About** — History, mission, vision, and team
3. **Services** — Garden maintenance and education services
4. **Products** — Soil & Seed database with search
5. **Get Involved** — Volunteer, donate, sponsor enquiry form
6. **Contact** — Contact form with validation
